# 🚚 Weather-Aware Truck Route Planner

A robust, real-time web application designed for intelligent trip planning, weather risk analysis, and optimized routing for freight and truck logistics.

## ✨ Key Features
- **Real-Time Weather Monitoring:** Evaluates live weather conditions along planned routes to prevent weather-related transit delays or hazards.
- **Dynamic Trip Configuration:** Custom inputs for origin, destination, departure time, and vehicle weight capacities.
- **Interactive Mapping:** Powered by Leaflet/React-Leaflet for precise route visualization and interactive checkpoint tracking.
- **Risk Assessment Sliders:** Visual sliders for corridor conditions and hazard mitigation metrics.

## 🛠️ Tech Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Icons & UI:** Lucide React, Motion
- **Mapping:** Leaflet & React-Leaflet
- **AI & Data Handling:** Google GenAI integration
